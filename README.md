# Pasindu Theekshana — Personal Portfolio Website

A modern, responsive, dark-themed personal portfolio website created to showcase my skills, projects, education, certifications, achievements, and contact information.

The portfolio was designed with a clean and professional developer-focused UI and is deployed live using Vercel.

## Live Website

https://pasindutheekshana.vercel.app

## About the Portfolio

This portfolio was developed to present my academic background, technical skills, development projects, and professional interests in a clear and interactive way.

It is designed for recruiters, internship opportunities, collaborators, and anyone interested in viewing my work and technical experience.

## Main Features

- Modern dark-themed UI
- Fully responsive design
- Smooth animations and transitions
- Interactive navigation
- Custom smooth cursor effects
- Hero section with personal profile image
- About Me section
- Technical skills showcase
- Education timeline
- Featured projects section
- Individual Project Overview pages
- Certifications section
- Achievements section
- Downloadable CV
- Contact form with email submission

The Contact section is integrated with Formspree.

- Success message
- Error handling
- Form reset after successful submission

## Responsive Design

The website is optimized for:

- Desktop
- Laptop
- Tablet

The portfolio includes a Download CV button that allows visitors to download my CV directly from the website.
